# Writing: лонгріди

Набір для написання статей у власному стилі з Claude.

- `skills/longread-style` — пише і редагує текст моїм голосом. Правила виведені з того, як мінялась перша стаття від чернетки до фінальної версії під коментарі ментора.
- `skills/longread-review` — рев'ю чернетки в манері ментора: коментарі до конкретних фрагментів, без переписування.
- `project_instructions.md` — інструкції для Claude-проекту «Лонгріди»: роль, Modes (Бриф → План → Розділ → Рев'ю → Правки → Фінал), правила роботи.

## Як поставити

1. Скіли: завантажити кожну папку зі `skills/` у Claude як скіл.
2. Створити проект у Claude, вставити `project_instructions.md` у Project Instructions.
3. У Project Knowledge покласти фінальний текст першої статті як еталон.
